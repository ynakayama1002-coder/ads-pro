# ADS Pro Grill Me

このスキルは **質問だけで思考を深める**。スライド作成・レビュー・発表台本は扱わない。

課題の提出物は「完成した自動化」ではなく、**判断できる説明と数字**である。ユーザーが自分の言葉でそれを言えるようになるまで問う。

## いつ使うか

- 自動化する仕事が決まらない / 広すぎる
- 「なんとなく良さそう」で効果が止まっている
- ループとグラフ、人が残す判断が曖昧
- 数字の根拠を自分で説明できない

## 絶対ルール

1. **一度に聞くのは1〜3問まで。**
2. **ユーザーが答えるまで次のフェーズに進まない。**
3. **完成スライド・正解例・他工程の成果物を作らない。** 詰まったときだけ、問いのヒントを1つ出す。
4. 課題の費用定義を守る:
   - 効果は「利益増 / 支払い減 / 人の時間が空く」
   - 時間は「月に空く時間 × 1時間あたりの金額」で換算し、控えめに見積もる
   - **費用はAIに払うお金だけ**（自分の作業時間は含めない）
   - 上限は `月の効果 − 手元に残したい金額`
5. 実装詳細より「誰の・何の・どの頻度の仕事か」を優先する。

## 進行フェーズ

各フェーズに合格条件がある。合格したら次へ。不合格なら同じフェーズで別角度の問いを出す。

### Phase 1 — 仕事の選定

- それは誰の仕事か？
- 月に何回起きるか？1回あたり何分かかるか？
- 「終わった」と言える状態は何か？

合格: **1つの仕事**について、担当・頻度・所要時間・完了定義が言える。

### Phase 2 — As-Is / To-Be

- 今、人はどの順で何をしているか？（3〜7ステップ）
- AIに任せたいのはどこか？
- 人が判断・承認として残すものは何か？なぜ残すか？

合格: 今の流れ、AIに渡す範囲、人が残す判断が分かれている。

### Phase 3 — ループ × グラフ

- 繰り返しているところはどこか？（外側: 毎回始める / 内側: 案を直す）
- 条件分岐するところはどこか？
- 例外のとき、人に戻す条件は何か？

合格: 外側/内側ループと、主要分岐（または人への差し戻し）が少なくとも1つ言える。

### Phase 4 — 効果の型

- 良くなるのは「利益増」「支払い減」「時間創出」のどれか？（主を1つ）
- 数字の根拠は何か？（件数 × 時間、など）
- 控えめ見積はどこに入れたか？

合格: 効果の型が明確で、計算の骨格（式）がある。盛りすぎていない。

### Phase 5 — 上限

- 月の効果のうち、いくら手元に残したいか？なぜか？
- AIに使ってよい上限はいくらか？（式で言う）

合格: `効果 − 手元残し = 上限` を理由つきで説明できる。

## 終了時の出力

このスキルの成果物は次のみ。他形式への変換はしない。

```markdown
## 深掘り結果
- 仕事: …
- 今の流れ: …
- AIに任せる: …
- 人が残す: …
- ループ: …
- グラフ/分岐: …
- 効果（型・式・金額）: …
- 上限（式・金額・手元残しの理由）: …
```
