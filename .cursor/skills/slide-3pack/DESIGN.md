# ADS Pro Slide 3-Pack デザイン仕様

確定デザイン: **Signal Numbers（案C）をメイン** + **Split Frame（案B）の問いレール**

## 方針

- 本編は常に3枚（仕事 / 効果 / 上限）
- 各枚の左レールに「枚番号 + 課題の問い」を固定表示
- 2・3枚目は金額などのシグナル数字を大きく見せる
- 1枚目は数字より「今 / AI / 人」の三分法を見せる
- 費用は AI に払うお金のみ

## レイアウト

```
┌────────┬─────────────────────────────┐
│ 01     │  メイン（タイトル / 本文）     │
│ 問い   │  2・3枚目は大数字を上部に     │
└────────┴─────────────────────────────┘
```

- 左レール幅: 約 22%
- 本編余白: 画面短辺の約 6%
- 箇条書き: 3〜5行

## 各枚の必須要素

1. 問いレール / タイトル / 今・AI・人
2. 問いレール / 大数字（効果金額） / 式 / 控えめ理由
3. 問いレール / 大数字（上限） / `効果 − 手元残し = 上限` / 理由
