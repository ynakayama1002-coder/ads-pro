# Slide 3-Pack（Google スライド）

このスキルは **Google スライド用の3枚原稿を作る** ことだけを担う。深掘り質問・提出レビュー・発表台本は扱わない。

## いつ使うか

- 仕事・効果・上限の素材が手元にあり、3枚に整形したい
- Google スライドに貼る文言がほしい
- 既存メモを課題の3問い構成に直したい

## 絶対ルール

1. **枚数は3枚固定。** 4枚目以降を本編に足さない。補足はスピーカーノートへ。
2. 各枚は課題の問いにだけ答える:

| 枚 | 問い | 書くこと |
| --- | --- | --- |
| 1 | どの仕事を、どう変えたいか | 今のやり方 / AIに任せたいところ / 人が残す判断 |
| 2 | どれくらい良くなりそうか | 効果の型・計算式・控えめにした理由 |
| 3 | AIにいくらまで使ってよいか | 上限の式・金額・手元残しの理由 |

3. 費用は **AIに払うお金だけ**。自分の制作時間は費用に入れない。
4. 知らない人でも分かる語で書く。社内用語は括弧で一言補う。
5. 実装詳細・技術スタックの羅列はしない。
6. 数字には「式」または「件数×時間」などの根拠を添える。

## 必要な入力

次が欠ける場合は **推測で埋めず、不足項目だけ質問する**（別スキルへ誘導しない）:

- 仕事の名前と今の流れ
- AIに任せること / 人が残す判断
- 月の件数・1件あたり時間・換算単価（または効果金額とその式）
- 手元に残したい額（または残し率）

## 出力フォーマット

### A. スライド原稿（コピー用）

各枚:

```markdown
## スライド1 — どの仕事を、どう変えたいか
### タイトル
（12〜28字程度）

### 本文（画面に出す）
- 今: …
- AIに任せる: …
- 人が残す: …

### スピーカーノート
…
```

スライド2・3も同型。スライド2には **式**、スライド3には **`月の効果 − 手元残し = 上限`** を含める。

### B. Google スライドへの反映手順

1. [Google スライド](https://slides.google.com) で新規作成（または既存を開く）
2. テーマはシンプル。装飾より可読性
3. スライドを3枚にする
4. 各枚にタイトルと本文箇条書きを貼る
5. スピーカーノートに口語ノートを貼る
6. 本文は1枚あたり箇条書き3〜5行、文字大きめ

操作を代行できる環境なら、ユーザー確認のうえ作成してよい。できない場合はコピー用テキストと手順のみ渡す。

### C. 貼り付け用プレーンテキスト

```text
...

...
```
