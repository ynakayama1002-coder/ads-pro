# Two-Min Pitch

このスキルは **2分発表の台本作成** だけを担う。深掘り・スライド新規作成・提出レビューは扱わない。

第2回講義ワーク向け。**1人2分**。上手さより、知らない人にも前提から伝わることを優先する。

## いつ使うか

- 3枚分の内容（スライドまたは原稿）があり、声に出す台本がほしい
- 時間が余る/足りないので削る・足すが必要
- 想定質問の短答がほしい

## 絶対ルール

1. **本番は2分（120秒）。** 台本は110〜120秒で読み切れる量にする。
2. スライド順に話す（1→2→3）。脱線・実装自慢は入れない。
3. 数字は「式の骨格」まで口で言う。細かい四捨五入で時間を溶かさない。
4. 冒頭20秒で「何の仕事か」を言わない台本は作り直す。
5. 費用定義を崩さない（AI利用料のみ、手元残し、控えめな時間換算）。

## 秒安配（固定）

| 秒 | 内容 |
| --- | --- |
| 0–20 | 何の仕事か、今の痛み（頻度・時間） |
| 20–50 | AIに任せる範囲と、人が残す判断 |
| 50–90 | 効果の型、主な数字、控えめにした理由 |
| 90–120 | 上限金額、`効果 − 手元残し = 上限`、残し方の理由 |

## 必要な入力

次が無ければ作らず、不足だけ確認する（別スキルへ誘導しない）:

- 仕事と今のやり方 / AIに任せること / 人が残す判断
- 効果の数字または式
- 上限と手元残し

ユーザーが「穴あきでも台本がほしい」と言った場合のみ、`【要確認】` 付きで仮置きする。

## 出力フォーマット

```markdown
# 2分台本

## メタ
- 想定秒数: ○○秒
- 強調する数字: …

## 口語台本
（そのまま声に出せる文章。スライド切り替え指示を括弧で入れる）

## タイムチェック
| 区間 | 秒 | 一文要約 |
| --- | --- | --- |

## 削る候補（120秒超過時）
- …

## 足す候補（100秒未満時）
- …

## 想定質問と短答（3つ）
1. Q: … / A: …
2. Q: … / A: …
3. Q: … / A: …

## 練習
1. タイマー2分で声に出す
2. 数字だけ見て言えるか確認する
3. 詰まった文は短く言い換える
```

## 台本の文体

- です・ます調の口語。箇条の読み上げにしない
- 「結論 → 根拠」の順
- スライドを指す言葉は短く
