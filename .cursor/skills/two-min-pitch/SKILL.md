# Two-Min Pitch

第2回講義ワーク向け。**1人2分**。上手さより、知らない人にも前提から伝わることを優先する。

## いつ使うか

- 3枚スライド（または合格済み原稿）がある
- 発表練習用の台本がほしい
- 時間が余る/足りないので削る・足すが必要

## 絶対ルール

1. **本番は2分（120秒）。** 台本は110〜120秒で読み切れる量にする。
2. スライド順に話す（1→2→3）。脱線・実装自慢は入れない。
3. 数字は「式の骨格」まで口で言う。細かい四捨五入の説明で時間を溶かさない。
4. 冒頭20秒で「何の仕事か」を言わない台本は不合格として作り直す。
5. 課題の費用定義を崩さない（AI利用料のみ、手元残し、控えめな時間換算）。

## 秒安配（固定）

| 秒 | スライド | 話すこと |
| --- | --- | --- |
| 0–20 | 1 | 何の仕事か、今の痛み（頻度・時間） |
| 20–50 | 1 | AIに任せる範囲と、人が残す判断 |
| 50–90 | 2 | 効果の型、主な数字、控えめにした理由 |
| 90–120 | 3 | 上限金額、`効果 − 手元残し = 上限`、なぜその残し方か |

## 入力が足りないとき

次が無ければ作らず確認する:

- 1枚目の仕事とAs-Is/To-Be
- 2枚目の効果数字（または式）
- 3枚目の上限と手元残し

未レビューなら、先に `assignment-reviewer` を勧めてよい。ただしユーザーが「とにかく台本」と言う場合は、穴を `【要確認】` 付きで仮置きする。

## 出力フォーマット

```markdown
# 2分台本

## メタ
- 想定秒数: ○○秒（読み上げ目安）
- 強調する数字: …

## 口語台本
（そのまま声に出せる文章。スライド切り替え指示を括弧で入れる）

## タイムチェック
| 区間 | 秒 | 一文要約 |
| --- | --- | --- |

## 削る候補（120秒超過時）
- …

## 足す候補（100秒未満時）
- …

## 想定質問と短答（3つ）
1. Q: … / A: …
2. Q: … / A: …
3. Q: … / A: …
```

## 台本の文体

- です・ます調の口語。箇条読み上げにしない
- 「結論 → 根拠」の順（例: 「上限は月○円です。効果○円のうち○円を手元に残すためです」）
- スライドを指す言葉は短く（「今見ている1枚目では…」）

## 練習の案内（最後に必ず書く）

1. タイマーを2分にセットして声に出す
2. 原稿を見すぎず、スライドの数字だけ見て言えるか確認する
3. 1回目で詰まった文は短く言い換える
4. 提出フォームへ提出（課題文のリンク先）
