# ads-pro

ADS Pro（AI-Driven School Pro）用の教材・課題・Agent スキル置き場。

## 構成

- `1st lecture` … `13th lecture` … 各回に `lecture-material/` と `monthly-assignment/`
- `1st group-session` … `6th group-session` … 各回に `lecture-material/` と `technical-assignment/`
- `.cursor/skills/` … 月次課題用 Agent スキル

フォルダ名は回次のみ（日付は入れない）。日程は必要なら各回のメモやスケジュール表で管理する。

詳細は `引き継ぎ.md` を参照。
