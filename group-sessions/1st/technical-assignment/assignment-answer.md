# 技術課題回答：AIが画像を生成する仕組み

- 回次: 1st group-session
- 締切: 2026-11-27（金）23:59（Asia/Tokyo）
- 提出: 2026-11-15（日）22:58（Asia/Tokyo）初回・最終

## 課題

文章の指示から画像を作る仕組みと、画像を読んで言葉にする仕組みを、400字以内で自分の言葉でまとめる。

## 提出回答

1. まずAIは膨大な学習段階で画像にノイズを加えそこからノイズを除去して元画像への復元する方法を学習している。その復元するパターンの中から、プロンプトに合う写真のイメージを合致させて、復元処理を行っていく。そのため、最初に与えられるランダムノイズが異なると同じプロンプトを実行したとしても、得られる結果が変わってくる。
2. 写真、画像を数値データへ変換し、数値化された色・形・模様・配置から特徴を抽出し学習した情報と突合する。特徴を的確に表現している、表している画像を特定する。画像から特定できない情報はネットから検索し、補足した上で回答する。

## グループセッションの感想

当たり前のように使っている技術の裏側について、全く疑問にも思っていなかったので、目から鱗だった。AIシステムは01で動いているので、白と黒で構成されているキャンバスに対して何か書くのは難しいのは、言われてみて理解ができた。そこからノイズに、ノイズ、ノイズかけられているもののパターンを学習していて、それを復元するという方法を用いられていることに対しては、新しい発見で、今後役立てられるかなと思う。
